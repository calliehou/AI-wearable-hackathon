## UI rules
- The wrist is the primary interface; the screen confirms. Every screen action needs a haptic or voice equivalent.
- One primary action per screen. Touch targets ≥ 44px.
- Contrast ≥ 4.5:1 for body text. Respect `prefers-reduced-motion`.
- Show privacy state clearly (what's listening, what's stored).
